AI4ALL 后台入口

运营后台和技术 Debug 的统一入口。默认视图只展示状态、元数据和审计信息。

—

运营后台

Admin
账号列表 查看账号状态、绑定、用量和最近活跃。 运行状态 查看 health、scheduler 心跳、消息和出站指标。 用户标签 查看账号级当前标签快照、陪伴类型和风险计数。 LLM Provider 查看底层模型配置、settings 默认和运行时 override。 实时入站 查看近 10 分钟 / 近 1 小时入站消息数，自动刷新。 内容审核后台 处理审核队列、查看风险详情、提交人工结论和管理员处置。 营销活码后台 创建/编辑内容创意营销活码，配置使命、onboarding 话术、SOUL 人设策略。 Reactivation 候选 查看所有账号当前 topic_followup / content_invitation 候选和发送时段。 Reactivation 历史 查看过去已发出的主动消息记录，按账号、日期筛选，含每日分布图。 明文授权 审批临时明文权限，跟踪授权状态。 访问审计 查看最近明文访问和高风险操作记录。

技术 Debug

Debug
Onboarding Debug 创建测试用户、跳 onboarding 状态、reset 上下文。 Reminder Debug 模拟聊天创建提醒，查看、编辑、取消测试提醒。 Proactive Debug 手动触发 scheduler、账号主动检查和内容邀请生成。 Web Search Debug 查看 web_search schema，写入模拟搜索 trace。 Prompt Lab Debug 查看 context files，编辑完整 LLM messages 并重放。 Swagger API 直接调用 Admin 和 Debug API。
