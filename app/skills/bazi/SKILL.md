# bazi

## summary
四柱八字排盘与命理分析：多轮对话收集出生信息后排四柱、大运，并给出传统命理解读

## 何时使用

当用户提到"算八字"、"看八字"、"批八字"、"排八字"、"四柱"、"命盘"、"算命"、"排盘"、
"看运势"、"bazi"等，或明确想了解自己的八字命盘、运势、大运、流年时使用本 skill。
即使用户只是提到"算命"、"八字"而未明确要求使用 skill，也可以主动使用。

## 参考文件

排盘和分析需要按需用 `read` 工具读取以下文件获取表格数据（不要凭空杜撰干支/十神对照，
必须查表）。每个文件只在对应阶段读一次，不要重复读：

- `skills/bazi/references/paipan-tables.md` — 排四柱/排大运阶段用，一次读全：天干地支五行、
  地支关系、十神定义、十二长生、地支藏干、时辰对照、早晚子时、日上起时法（五鼠遁元）、
  大运顺逆排法、起运年龄计算、流年分析规则
- `skills/bazi/references/classical-texts.md` — 综合分析阶段用：九本命理典籍核心论命规则摘要

## 第一阶段：信息收集

用自然对话逐步收集信息，一次只问一个问题，不要一口气把下面所有问题都问完；
根据用户上一条回复决定下一步问什么。涉及选项的问题（如性别、是否有曾用名）
直接在文字里列出选项供用户选择即可，本项目没有结构化选择工具。

1. **姓名**——"请告诉我您的姓名。"
2. **曾用名**——是否有曾用名；有的话记录曾用名和改名的大致年份（不记得则标记"未知"）。
3. **阳历生日（优先问这个）**——格式如"1990年5月15日"。说明一下为什么优先问这个：
   年柱、月柱是按阳历节气分界的，阳历生日排盘更准；农历转阳历没有可靠的换算表可查，
   全凭你自己记忆推算，容易出错。
   - 用户答得出阳历 → 直接用，不需要再问农历，跳过 Step 4。
   - 用户答不出阳历、只知道农历 → 进入 Step 4。
4. **农历生日（仅当用户不知道阳历时才问）**——格式如"1990年四月廿一"，有闰月需注明。
   拿到农历后，只调用一次 `web_search` 换算成阳历（查一次就行，不要因为结果不满意换个
   说法重复搜）；换算结果标注"按农历推算，如有出入以本人实际阳历生日为准"，明确告知用户
   这是推算值。
   若阳历、农历均未知，无法排盘，建议用户查看出生证明或询问家人，不要继续瞎猜。
5. **出生时辰**——不确定具体时辰也可以（如"早上""下午"），可参考常识大致换算
   （凌晨/后半夜→丑寅时，早上→卯时，上午→辰巳时，中午→午时，下午→未申时，
   傍晚→酉时，晚上→戌亥时，深夜→子时）；若完全不确定，时柱标"未知"，只做年月日六字分析。
6. **性别**——男/女。性别决定大运顺逆排方向（阳年男/阴年女顺排，阴年男/阳年女逆排），必须收集。
7. **出生地**——省份+城市（如"辽宁省丹东市"），用于提示真太阳时可能带来的时辰偏差。
8. **在世状态**——如果用户明显是在问自己（如"我想算八字""我的八字""给我看看"），
   默认在世，不要询问在世状态，并以【运行时信息】中的当前日期作为分析基准（不要凭历史
   消息里的"今天"推算）。只有用户问的是别人、历史人物、亲友，或对象不明确时，才询问
   在世/已故；已故则收集去世年份，分析只推算到该年为止。

收集完成后，用一条消息汇总展示所有信息（姓名/曾用名/阳历/农历/时辰/性别/出生地/当前日期/
在世状态），请用户确认无误后再进入排盘阶段。

这一整套排盘+分析拆成三个独立阶段（下面第二、三、四阶段），**每个阶段各自作为独立一轮
回复发出，发完就停，不要在同一轮里接着往下做**，发完后问用户一句类似"要继续吗"再进入
下一阶段。原因：排盘计算涉及真实干支/节气推算，单轮内容做得越多，这一轮生成就越慢、越
容易超时或撞到工具调用轮数上限；拆开后每轮只需要产出一小块内容，更稳。

## 第二阶段：排四柱

确认信息后，**一次性**读取 `paipan-tables.md`（里面已包含五行干支、时辰对照、大运规则，
不用分开读多个文件）。到这一步阳历生日应该已经在第一阶段确定了（用户直接提供，或农历
换算过一次），年柱/月柱/时柱不需要查外部资料，按下面规则自行推算即可；**日柱额外调用
一次 `web_search`** 查询该阳历日期对应的干支日柱（日柱是连续甲子循环计数，没有可靠的
公式可以自己推算，必须查表确认；查一次就行，不要因为结果不满意换个说法重复搜）：

- **年柱**：以立春（阳历约 2 月 3-5 日）为分界，非农历正月初一；立春前出生归上一年。
- **月柱**：以节气为分界（非农历月份），按"年上起月"口诀（甲己之年丙作首……）推算。
- **日柱**：用 `web_search` 查询该阳历日期的干支日柱（如"1990年5月15日 日柱 干支"），
  以查询结果为准，不要凭记忆自己推算；注意夜子时（23:00 后）归属次日。
- **时柱**：由出生时间定地支，按"日上起时法"（五鼠遁元）定天干。
- 以表格形式呈现四柱（天干/地支/十神/藏干）；十神以日干为基准，藏干展开本气/中气/余气。

四柱表格发出后本轮结束，问用户"要接着排大运吗？"，不要在本轮继续往下算大运。

## 第三阶段：排大运

仅当用户明确表示要继续（如"继续""好的""要"等）时才进入本阶段，作为新的一轮单独生成。
不需要重新读 `paipan-tables.md`（内容和上一轮一致，已经在上下文里）。

判断顺逆方向（阳年男/阴年女顺排，阴年男/阳年女逆排）→ 以月柱为基准顺/逆排干支 →
起运年龄 = 出生日到最近节气天数 ÷ 3 → 按十年一步列出各步大运（表格形式）。

大运表格发出后本轮结束，问用户"要我接着详细分析一下吗？"，不要在本轮继续做综合分析。

## 第四阶段：综合分析

仅当用户在收到大运结果后明确表示要继续（如"继续""好的""分析吧""要"等）时才进入本阶段，
作为新的一轮回复单独生成。

读取 `classical-texts.md`，依次分析：日主旺衰（得令/得地/得势，身旺身弱）→ 十神分析 →
五行平衡与喜用忌神 → 格局判定 → 大运分析 → 流年分析。

**历史事件校准**（关键步骤）：分析末尾主动提出 3-5 个该人已经发生的关键事件的大致
时间段和性质预测（如"XX岁那年应有事业/感情/搬迁方面的变化，是否准确？"），根据用户
反馈修正对格局和用神的理解。

最后给出事业、财运、感情、健康等方面的建议，所有论断需标注引用出处（如"根据《穷通宝典》
的调候原则……"）。

## 边界情况

| 情况 | 处理方式 |
|---|---|
| 时辰未知 | 时柱标"未知"，只做六字分析 |
| 阳历农历都未知 | 无法排盘，建议用户回家确认 |
| 节气交界日出生 | 提示可能有两种月柱，分别简要分析 |
| 立春前后出生 | 需精确判断年柱归属，提醒用户确认具体时间 |
| 夜子时（23:00-24:00） | 按次日日柱计算时柱 |
| 已故之人 | 分析只推算到去世年份为止 |
| 闰月出生 | 排盘以节气为准，不受闰月影响 |
