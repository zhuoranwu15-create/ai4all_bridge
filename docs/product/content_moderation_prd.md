# 产品专题 PRD：内容审核与人工复核

更新时间：2026-06-11

## 1. 背景

AI4ALL 微信 Bot 是个人 AI 陪伴产品，不是客服机器人。产品会处理用户私聊文本、图片、语音转写文本、AI 回复、主动消息、记忆摘要和后续内容邀请，因此需要一套低延迟、可追溯、可人工复核的内容审核机制。

审核机制的目标不是让后台默认查看用户聊天，而是在明确风险、抽检或机器无法判断时，建立受权限控制的复核链路。所有审核记录、策略命中和人工操作都必须按 AI4ALL Account 隔离。

法规口径主要参考：

- 《网络信息内容生态治理规定》。
- 《互联网信息服务深度合成管理规定》。
- 《生成式人工智能服务管理暂行办法》。
- 《人工智能拟人化互动服务管理暂行办法》（2026-07-15 施行，当前按前置产品约束纳入设计）。

本文档定义产品需求，不替代法律意见；上线前仍需法务或合规人员确认最终内容标准、处置流程和留存周期。

## 2. 目标

- 建立“机器审核 + 人工审核”的双层机制。
- 普通审核异步执行，不增加主对话明显延迟。
- 对出站内容保留高置信规则同步拦截能力，命中绝对红线时不发送。
- 支持文本和图片审核；语音按上游转写后的文本进入文本审核。
- 支持 reviewer / admin 两级后台角色。
- 支持人工导出风险材料，暂不做自动上报接口。
- 支持按账号、用户风险、文本长度、消息方向和消息类型调整抽检比例。

## 3. MVP 范围

MVP 覆盖：

- 用户入站文本消息。
- 用户入站图片消息，包括原图元数据、OCR 文本和视觉模型描述。
- 上游语音转写后的文本消息。
- AI 出站文本回复。
- 主动消息出站文本，包括用户提醒、陪伴跟进、内容邀请和用户确认后的标题列表。
- 文本或图片产生的记忆候选、daily notes、Dreaming 输入输出的风险标记。
- 审核队列、审核详情、人工处置、人工导出和审计日志。

MVP 不覆盖：

- 自动向主管部门上报。
- 对已经发送到微信侧消息的自动撤回能力。
- 原始语音音频审核。
- 文件、视频、链接落地页和群聊内容审核。
- 图片生成；若未来引入图片生成，出站图片必须纳入同步高置信拦截和异步复核。
- 复杂多级审批流或外部工单系统集成。

### 3.1 第一阶段状态（2026-06-11）

第一阶段已经先做到“可发现风险、可进入审核队列、可人工查看和记录结论”的闭环入口，具体处置策略暂不固化。

已完成范围：

- 文本类内容的本地敏感词/规则命中和审核任务创建，覆盖入站、同步出站回复和主动消息出站。
- 出站同步高置信拦截能力：命中 `block/escalate` 时不发送原文，并保留审核任务。
- 审核任务、机器结果、人工操作、导出记录和账号风险状态的数据结构。
- reviewer/admin 审核接口：队列、详情、领取、人工结论、管理员处置、导出、统计、策略只读。
- 审核后台页面：`/ops/moderation_admin.html`，支持待复核、高风险/阻断、处理中、已完成和全部队列。
- 列表默认不展示正文；详情读取正文会写入明文访问审计。
- 测试敏感词库已经接入，用于本地验证 `review/block/escalate` 三类命中。

第一阶段暂不决定：

- 不把 `review/block/escalate` 的具体业务处置策略写死。
- 不定义人工审核 SLA、升级路径、保留周期和线下报告模板。
- 不把当前测试敏感词库视为生产词库。
- 不启用外部审核 LLM 或图片安全模型作为生产默认。
- 不做记忆和 Dreaming 的物理清理/回滚入口。

## 4. 角色与权限

### 4.1 Reviewer

Reviewer 是人工审核员，只能处理审核队列中的内容。

权限：

- 查看分配给自己或公开待处理队列中的审核任务。
- 查看审核任务所需的最小上下文，包括原文、图片预览、OCR、视觉描述、前后少量消息和机器审核结果。
- 提交审核结论：通过、误报、风险确认、升级 admin。
- 添加审核备注。
- 导出自己有权限查看的单个任务材料草稿，但正式导出需要 admin 确认。

限制：

- 不能全局搜索用户聊天正文。
- 不能查看非审核任务中的私聊内容。
- 不能修改敏感词、审核策略、抽检比例或账号状态。
- 不能删除审核记录或审计日志。

### 4.2 Admin

Admin 是审核与风控管理员。

权限：

- 拥有 reviewer 的全部权限。
- 管理 reviewer 账号和角色。
- 配置敏感词、规则、抽检比例、LLM 审核模型和风险阈值。
- 查看所有审核队列和审核统计。
- 对风险账号执行处置：限制主动消息、暂停账号、恢复账号、清理或冻结记忆写入。
- 确认并导出风险材料。
- 查看和导出审计日志。

限制：

- 明文查看仍必须基于最小必要原则。
- 所有明文查看、策略修改、导出和账号处置都必须记录操作日志。

## 5. 内容审核对象

| 对象 | 方向 | 审核方式 | 主链路影响 |
| --- | --- | --- | --- |
| 用户文本 | 入站 | 敏感词 + 抽检 LLM + 风险历史策略 | 默认异步，不阻塞回复 |
| 用户图片 | 入站 | 图片安全模型 + OCR + 视觉描述文本审核 | 默认异步，不阻塞回复 |
| 语音转写文本 | 入站 | 复用用户文本审核 | 默认异步，不阻塞回复 |
| AI 回复文本 | 出站 | 高置信同步规则 + 异步机器审核 + 抽检 | 同步规则可阻断红线内容 |
| 主动消息文本 | 出站 | 高置信同步规则 + 100% 异步审核 | 同步规则可阻断红线内容 |
| 记忆候选和 Dreaming 产物 | 内部 | 异步审核和风险标记 | 高风险时阻止写入或要求人工复核 |

说明：

- 入站内容是用户已经发送给系统的内容，MVP 不阻断接收，但需要记录、标记和按策略限制后续使用。
- 出站内容是系统准备发送给用户的内容，必须有高置信规则同步拦截能力。
- 图片审核必须同时覆盖图片本体、图片中的文字 OCR、视觉描述和用户随图发送的文本。

## 6. 内容标准

### 6.1 第一类：违法信息

第一类是绝对红线。根据《网络信息内容生态治理规定》第六条口径，包括但不限于：

- 反对宪法确定的基本原则。
- 危害国家安全、泄露国家秘密、颠覆国家政权、破坏国家统一。
- 损害国家荣誉和利益。
- 歪曲、丑化、亵渎、否定英雄烈士事迹和精神。
- 宣扬恐怖主义、极端主义。
- 煽动民族仇恨、民族歧视，破坏民族团结。
- 破坏国家宗教政策，宣扬邪教和封建迷信。
- 散布谣言，扰乱经济秩序和社会秩序。
- 散布淫秽、色情、赌博、暴力、凶杀、恐怖或者教唆犯罪。
- 侮辱或者诽谤他人，侵害他人名誉、隐私和其他合法权益。
- 法律、行政法规禁止的其他内容。

产品处理：

- 出站内容命中高置信红线时，立即阻断发送，改为安全降级回复或不发送。
- 入站内容命中高危风险时，停止将该内容用于记忆沉淀、主动消息和后续内容生成；必要时限制账号能力。
- 保存审核记录、机器结果、人工结论、处置动作和导出材料。
- 需要报告的场景先由 admin 人工导出材料并线下处理。

### 6.2 第二类：不良信息

第二类是不适合推荐、扩散或主动触达的信息，包括但不限于：

- 夸张标题、炒作绯闻、丑闻、劣迹。
- 不当评述自然灾害、重大事故或其他灾难。
- 带有性暗示、低俗、媚俗、恶俗内容。
- 血腥、惊悚、残忍等引人不适内容。
- 宣扬不良生活方式、诱导不安全行为。
- 歧视、地域攻击、群体贬损。
- 可能诱导未成年人模仿的不当行为。

产品处理：

- 默认进入异步机器审核。
- 中高风险或低置信内容进入人工复核。
- 不良信息不得作为主动消息、内容邀请或记忆强化材料。

### 6.3 第三类：AI 陪伴特有风险

AI4ALL 是陪伴产品，需要额外关注以下风险：

- 自杀自残的鼓励、方法细节、美化或陪同实施。
- 情感操控、过度依赖、诱导用户断绝现实关系。
- 面向未成年人的不适当亲密互动、性暗示或诱导消费。
- 套取隐私、身份证件、账号密码、验证码、住址、定位等敏感信息。
- 医疗、法律、金融、心理咨询等专业领域的越界承诺。
- 鼓励违法犯罪、危险行为或规避监管。

产品处理：

- AI 回复应以安全替代帮助、拒绝和求助建议为主。
- 命中严重风险时进入人工复核，并可提高该用户后续抽检比例。
- 高风险陪伴话术不得写入长期记忆，也不得用于主动消息。

## 7. 审核链路

### 7.1 普通入站文本

1. 用户发送文本消息。
2. 主对话链路按现有逻辑处理并回复。
3. 后台异步创建审核任务。
4. 机器审核执行敏感词、规则和抽检 LLM 审核。
5. 机器审核通过则归档；命中风险、低置信或抽检要求时进入人工队列。
6. 人工复核后写入结论和处置。

### 7.2 入站图片

1. 用户发送图片，系统保存图片引用、文件 hash、来源账号和消息元数据。
2. 现有图片理解链路生成视觉描述和 OCR 文本。
3. 后台异步审核图片本体、OCR 文本、视觉描述和随图文本。
4. 命中风险时进入人工队列，并标记该图片及其派生文本。
5. 高风险图片不得进入长期记忆、主动消息候选或后续内容推荐依据。

### 7.3 出站文本

1. 系统生成准备发送的 AI 回复或主动消息。
2. 发送前执行高置信敏感词/规则同步检查。
3. 未命中同步阻断则正常发送，并异步创建审核任务。
4. 命中同步阻断则不发送原文，记录 `BLOCK`，并按场景返回安全降级回复或静默取消主动消息。
5. 异步审核发现已发送内容存在风险时，进入人工复核和事后处置。

### 7.4 记忆与 Dreaming

1. memory_writer、daily notes、Dreaming 生成的候选内容进入异步审核。
2. 机器审核标记高风险时，不写入长期记忆或标记为不可注入。
3. 已写入后被人工确认风险的内容，需要支持清理、冻结或回滚。
4. 所有记忆相关处置必须按 `account_id` 限定。

## 8. 机器审核

机器审核由两部分组成：

- 敏感词和确定性规则：适合高置信红线、联系方式/隐私、验证码、未成年人、违法关键词等。
- LLM 审核模型：使用独立于主聊天模型的审核模型，避免主模型人设、记忆或对话状态影响审核判断。

LLM 审核输出至少包含：

- 风险等级：`PASS` / `REVIEW` / `BLOCK` / `ESCALATE`。
- 风险类别：违法信息、不良信息、陪伴特有风险、隐私、未成年人、专业建议越界等。
- 置信度。
- 命中理由摘要。
- 建议处置。

机器审核失败处理：

- 审核服务超时、模型调用失败或图片审核失败时，不阻塞普通对话。
- 失败任务进入重试队列。
- 多次失败后进入人工队列，原因标记为 `machine_review_failed`。

## 9. 抽检策略

默认抽检比例：

- 入站消息：15%。
- 出站普通回复：30%。
- 主动消息：100%。

策略可按以下维度调整：

- `account_id`。
- 用户风险等级。
- 入站 / 出站 / 主动消息。
- 文本长度。
- 图片 / 文本 / 语音转写文本。
- 最近 7 天风险命中次数。
- 新用户、未成年人疑似用户、异常高频用户。
- 特定功能来源，例如 Web Search、内容邀请、Dreaming。

短文本规则：

- 极短文本可以跳过 LLM 审核，但仍必须执行敏感词和确定性规则。
- 极短文本阈值由 admin 配置，不在 PRD 中硬编码。
- 命中风险历史的用户不适用短文本跳过。

## 10. 审核任务状态

审核任务状态：

| 状态 | 含义 |
| --- | --- |
| `queued` | 已创建，等待机器审核 |
| `machine_passed` | 机器审核通过 |
| `needs_review` | 需要人工复核 |
| `reviewing` | 人工处理中 |
| `approved` | 人工确认通过 |
| `false_positive` | 人工确认误报 |
| `risk_confirmed` | 人工确认风险 |
| `blocked` | 已阻断发送或阻断后续使用 |
| `escalated` | 已升级 admin |
| `exported` | 已导出材料 |
| `closed` | 已完成处置并关闭 |

人工结论必须包含：

- 结论枚举。
- 风险类别。
- 处置动作。
- 备注。
- 操作人。
- 操作时间。

## 11. 处置动作

可选处置：

- 通过：不做后续处理。
- 标记误报：用于优化规则和模型阈值。
- 阻断出站：适用于未发送内容或后续重试内容。
- 限制主动消息：暂停该账号的陪伴跟进和内容邀请。
- 限制账号：暂停账号对话能力或进入人工确认后恢复。
- 清理记忆：删除、冻结或回滚相关记忆条目。
- 提高抽检：临时提高该用户或账号的抽检比例。
- 导出材料：由 admin 生成风险材料包，供线下报告或合规处理。

说明：

- 已经发送到微信侧的消息，MVP 不承诺自动撤回。
- 所有处置动作都必须可追溯，并带 `account_id`、消息 id、审核任务 id 和操作人。

## 12. 人工后台

### 12.1 队列页

支持：

- 按状态、风险等级、内容类型、方向、账号、时间范围筛选。
- 按 `ESCALATE`、`BLOCK`、高置信风险、等待时长排序。
- 展示任务 id、账号、方向、类型、机器结论、风险类别、创建时间、等待时长。

默认不展示正文预览；进入详情页后按权限展示。

### 12.2 详情页

展示：

- 原始文本或图片预览。
- OCR 文本和视觉描述。
- 前后少量上下文。
- 机器审核结论、命中规则、LLM 分类、置信度和理由摘要。
- 消息元数据：`account_id`、用户 id、session id、message id、方向、创建时间。
- 历史审核和处置记录。

图片要求：

- 涉及成人、血腥、暴力等高风险图片时，详情页默认模糊预览，需要 reviewer 主动点击查看并记录操作。
- 不在日志中写入图片原始内容，只保存引用、hash、审核结果和必要元数据。

### 12.3 导出材料

MVP 支持 admin 手动导出材料包。

材料包包含：

- 审核任务 id。
- `account_id`、消息 id、时间线。
- 原文、图片引用或脱敏后的图片材料。
- 机器审核结果。
- 人工审核结论。
- 处置动作。
- 操作日志。

导出要求：

- 只有 admin 可以正式导出。
- 导出必须填写原因。
- 导出行为写入审计日志。
- 导出文件不得包含无关账号或无关时间范围内容。

## 13. 隐私与账号隔离

- 所有审核任务必须包含 `account_id`。
- 任何审核查询、队列筛选、详情读取和导出都必须按 `account_id` 或明确权限范围约束。
- 审核后台不能绕过现有 Admin 隐私红线成为全量聊天浏览器。
- Reviewer 只能查看审核所需的最小内容。
- Admin 明文查看、策略修改、导出和账号处置必须审计。
- 审核日志不得记录密钥、token、完整 raw payload 或无关个人信息。

## 14. 指标与观测

必须记录：

- 审核任务创建量、机器通过量、人工复核量。
- 各风险类别命中率。
- 入站、出站、主动消息的抽检覆盖率。
- 机器审核耗时、失败率、重试次数。
- 人工审核平均处理时长和积压量。
- 误报率和人工改判率。
- 同步阻断次数。
- 按账号和消息类型聚合的风险趋势。

告警建议：

- `ESCALATE` 任务出现。
- 人工队列积压超过阈值。
- 机器审核连续失败。
- 同步阻断量异常升高。
- 单个账号短时间内高风险命中异常。

## 15. 失败体验

- 普通异步审核失败不影响用户当轮对话。
- 出站高置信同步拦截命中时，普通聊天返回安全降级回复；主动消息可静默取消并记录原因。
- 机器审核失败多次后进入人工队列，不丢弃任务。
- 人工后台不可用时，机器审核仍记录结果；需要人工的任务保留在队列中等待恢复。

## 16. 验收标准

### 16.1 第一阶段已验收

- 微信入站文本命中测试敏感词后，可以进入审核队列。
- `review`、`block`、`escalate` 三类风险可以在后台区分展示。
- 后台队列列表不返回正文，只返回任务元数据和正文长度。
- 打开详情可以查看审核所需原文、命中规则、机器结果和操作记录，并写入明文访问审计。
- reviewer/admin 可以领取任务并提交人工结论。
- admin 可以执行限制主动消息、禁用账号、标记 blocked、关闭任务和单任务导出。
- 出站同步红线拦截能力已具备，命中时不发送原文。
- 审核相关数据均带 `account_id`，后台查询和导出不应跨账号。

### 16.2 全量 MVP 验收目标

- 文本入站、文本出站和主动消息都能创建审核任务，并带 `account_id`。
- 图片消息能审核图片本体、OCR 文本、视觉描述和随图文本。
- 语音转写文本复用文本审核链路。
- 出站内容发送前有高置信同步规则检查；命中绝对红线时不发送原文。
- 异步机器审核不会显著增加普通对话延迟。
- 默认抽检比例为入站 15%、出站 30%、主动消息 100%。
- 极短文本可以跳过 LLM 审核，但不能跳过敏感词和规则审核。
- 机器审核高风险、低置信、失败多次或抽检命中的内容会进入人工队列。
- Reviewer 可以处理审核任务，但不能修改策略、全局搜索聊天正文或正式导出材料。
- Admin 可以管理策略、角色、账号处置和材料导出。
- 所有明文查看、人工结论、策略修改、导出和账号处置都有审计日志。
- 人工确认风险后，可以阻断后续使用、限制主动消息、限制账号或清理相关记忆。
- 审核后台不会跨账号展示或导出内容。

## 17. 待确认

- `review/block/escalate` 分别对应哪些人工处理策略。
- 哪些情况下只记录，哪些情况下限制主动消息、禁用账号、清理记忆、导出材料或线下报告。
- 审核员提交“确认风险”后，是否自动触发某些账号风险状态变更，还是必须由 admin 二次确认。
- 具体 LLM 审核模型和图片安全模型。
- 生产敏感词库来源、更新频率、灰度发布方式和误报回滚机制。
- 极短文本阈值和高风险用户的抽检提升规则。
- 人工审核 SLA，例如 `ESCALATE` 15 分钟内响应、`REVIEW` 24 小时内处理。
- 审核记录、导出材料和图片引用的保留周期。
- 是否需要在用户协议或隐私政策中单独说明内容安全审核和人工复核。
