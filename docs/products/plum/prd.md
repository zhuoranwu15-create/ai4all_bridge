# Plum 产品需求文档

更新时间：2026-08-11

> 归属：`product:plum`。本文是 Plum 产品总 PRD，先冻结产品愿景、价值原则、核心体验与
> 能力边界；具体注册、onboarding、聊天、上下文、内容、安全和商业化策略将在实施过程中
> 拆分为专题 PRD。未在本文冻结的细节不视为已承诺需求。

## 1. 产品定位

Plum 是面向海外用户的 AI 角色聊天与互动内容产品。用户可以发现感兴趣的角色和故事，选择
自己的身份进入情境，通过持续对话建立关系、推动剧情，并在后续逐步参与角色与内容创作。

Plum 初期产品形态参考 Talkie、Tipsy 等 AI 角色互动产品，但不以复制既有功能为目标。产品将
持续探索 AI 原生的内容形态、关系体验和创作方式，并把聊天智能作为核心竞争力：角色应当稳定、
鲜活、有记忆，能够理解用户意图、把握互动节奏，同时尊重用户的选择与边界。

Plum 不是通用效率助手、客服机器人，也不以替代真实人际关系为目标。它首先提供安全、沉浸、
有持续感的虚拟角色互动体验。

## 2. 产品愿景

让每个用户都能进入一个真正理解自己、会持续生长的互动故事，并让优秀的 AI 角色与内容被更低
门槛地创造、发现和分享。

长期来看，Plum 希望形成由三部分共同驱动的产品：

- 极致的 AI 互动体验：对话自然，角色一致，记忆可靠，叙事有张力；
- 丰富的互动内容生态：用户可以发现、收藏、参与并逐步创造角色和故事；
- 健康可持续的社区与商业系统：创作者、用户和平台获得长期价值，而不是依赖伤害体验的短期增长。

## 3. 价值目标与决策原则

Plum 在产品决策中同时考虑用户价值、商业价值和社会价值。

### 3.1 用户价值

- 提供高质量的陪伴、角色扮演、故事体验和情绪表达空间；
- 让用户对自己的身份、关系走向、内容偏好和数据拥有清晰控制；
- 通过连续记忆和关系发展，让每次互动不是从零开始；
- 降低 AI 内容创作门槛，让普通用户也能表达想象力。

### 3.2 商业价值

- 以高质量互动带来留存和口碑，而不是用强制打断或诱导机制透支信任；
- 建立与模型成本匹配的订阅、虚拟权益和增值体验；
- 在条件成熟后形成对优质创作者友好的内容供给与激励机制；
- 兼顾体验质量、增长效率、单位经济性和长期品牌价值。

### 3.3 社会价值

- 明确 AI 身份，不诱导用户误认为角色是真人；
- 尊重同意、隐私、多样性和文化差异，避免操纵、歧视与有害依赖；
- 对未成年人、成人内容、高风险建议和危机情境建立清晰边界；
- 为举报、屏蔽、申诉、数据导出与删除提供可理解的机制。

当三类价值发生冲突时，安全与用户基本权益是底线；在底线之上，优先创造真实用户价值，并用可
持续的商业方式支持长期产品创新。

## 4. 目标用户与核心需求

初期目标用户包括：

- 希望轻松发现有吸引力角色、快速进入互动的内容探索者；
- 重视角色一致性、关系连续性和故事沉浸感的深度互动用户；
- 希望塑造“自己在故事中的身份”并掌控情节方向的角色扮演用户；
- 希望创建角色、设定世界观并获得反馈的潜在创作者。

核心用户需求是：“帮我快速找到一个想聊的角色，让互动足够聪明、沉浸且持续，并让我始终拥有
选择权。”

## 5. 核心产品闭环

```text
发现角色与故事
    -> 查看角色、场景和内容边界
        -> 选择用户身份并开始对话
            -> 形成记忆、关系与故事进展
                -> 回访、收藏、分享或探索新内容
                    -> 逐步参与角色与内容创作
```

产品首先验证“发现—首次互动—持续回访”的闭环，再逐步扩展创作、社区和商业能力。

## 6. 身份与资产基础模型

Plum 将账号权利主体、故事身份、关系连续性和具体剧情分开建模：User 是登录、数据权利、
安全控制和付费主体；一个 User 可以拥有多个 Persona；Persona 与 Character 建立
Persona–Character Connection，并在其中维护关系和跨剧情共同记忆；Storyline 承载具体剧情，
Conversation 推进 Storyline。

收藏、屏蔽、举报、角色访问权益等不随 Persona 切换的能力属于 User，不建立含糊的
“User–Character State”；关系、称呼和共同经历属于 Persona–Character Connection；剧情状态、
局部剧情记忆和会话属于 Storyline。Persona 在首次建立 Connection 后锁定且不再修改；Character
需要版本化，发布新版本后已有 Connection 自动采用新版本并保留升级记录。同一组 Persona + Character
同时只能存在一段 active Connection，重开归档旧 Connection 后创建新 Connection。完整名词、
归属、版本、重开和删除规则见
[账号、身份与资产关系](identity-and-assets.md)。

## 7. 核心体验支柱

### 7.1 极致聊天智能

- 准确理解用户显式意图和隐含语境，回应自然、有情绪和节奏感；
- 长期保持角色身份、语言风格、关系边界和世界设定一致；
- 可靠使用会话、用户身份、关系进展和长期记忆，避免串线与虚假记忆；
- 既能回应用户，也能在合适时主动推动互动，但不替用户决定行动或台词；
- 在延迟、流式输出、失败恢复、重试和成本之间保持稳定体验。

### 7.2 互动内容发现

- 通过 Feed、标签、主题和个性化推荐降低发现成本；
- 角色卡应清楚表达人物、场景、内容分级和互动预期；
- 推荐不仅追求点击，也关注首次互动质量、长期满意度与内容多样性。

### 7.3 连续关系与故事

- 不同 User、Persona、Connection 和 Storyline 的对话、关系、记忆与进度按对应作用域隔离；
- 用户可以回到已有关系；执行重开时必须新建 Connection，旧关系、记忆、剧情和会话上下文不继承；
- 关系成长应来自真实互动，不通过虚假稀缺、威胁或情绪操纵强迫留存。

### 7.4 用户表达与创作

- 用户可以定义自己在故事中的称呼、身份、偏好和边界；
- 后续支持用户创建角色、场景和开场，并通过预览和测试改善体验；
- 创作者内容必须具备版本、归属、审核、下架和申诉机制；Character 下架后已有 Connection 也不能继续；

### 7.5 安全、可信与可控

- 在发现、角色详情、对话生成和公开内容等环节形成完整安全链路；
- 为用户提供内容偏好、屏蔽、举报、会话重置和数据删除能力；
- 固定规则、模型审核和人工复核相互补充，并适配首发市场的语言和法规。

## 8. 初期产品范围

初期优先建立：

- 海外用户注册、登录、session 与产品 membership；
- 新用户 onboarding、年龄与条款确认、基础偏好和用户身份设置；
- 角色 Feed、角色详情、标签、收藏和基础反馈；
- 文本流式聊天、历史会话、取消、恢复与明确重开；
- 角色人格、用户身份、会话上下文和长期记忆的稳定组装；
- 基础关系进展、内容分级、审核、举报和账号数据管理；
- 可观测的权益与成本底座，为后续订阅和增值体验保留空间。

初期不承诺完整创作者市场、创作者分成、真人社交、复杂游戏化、开放式 Agent 工具生态或所有国家
同时上线。成人内容是否进入首发范围，必须在年龄保障、地区政策和审核能力明确后单独决策。

## 9. 产品原则

- 智能即产品：聊天质量不是底层能力指标，而是用户直接感知的核心产品体验；
- 内容与模型共创：角色设定、上下文、记忆、推荐和模型行为需要作为一个整体设计；
- 用户拥有方向盘：AI 可以创造惊喜，但不得替用户做关键决定或绕过明确边界；
- 连续而不失控：记忆和关系应增强长期体验，同时必须可查看、重置和删除；
- 全球化默认：文案、内容、安全、时区、支付和数据处理从一开始按多语言、多地区设计；
- 克制增长：不使用欺骗、焦虑、羞辱或情绪勒索换取互动时长和付费；
- 实验驱动创新：新交互与商业机制先小范围验证用户价值、安全影响和单位经济性。

## 10. 核心指标框架

北极星指标暂定为“每周有意义互动用户数”，具体定义需要结合首轮数据校准。指标分为：

- 激活：完成 onboarding、打开首个角色、完成首个有效多轮会话；
- 体验：回复成功率、首字延迟、角色一致性、记忆有效性、主动重试/退出与用户反馈；
- 留存：次日、7 日、30 日回访，以及同一角色关系的持续互动；
- 内容：角色曝光到开聊转化、有效会话率、收藏、举报和内容多样性；
- 商业：付费转化、收入、退款、模型成本和每次有意义互动成本；
- 社会与安全：高风险命中、误伤、举报处理、申诉、屏蔽与用户数据请求完成情况。

任何单一互动时长或收入指标都不能脱离满意度、安全和长期留存单独优化。

## 11. 后续专题 PRD

后续需求按真实实施节奏逐步建立，不预先复制其他产品的文档结构：

- 注册、鉴权与账号生命周期；
- 新用户 onboarding 与偏好冷启动；
- 角色聊天与智能体验；
- Context Files、记忆与关系连续性；
- 角色发现、推荐与互动内容；
- 用户角色、创作工具与内容治理；
- 审核、年龄保障、隐私与地区合规；
- 权益、订阅、增值体验与创作者激励；
- 数据指标、实验与运营平台。

## 12. 当前待确认问题

- 首发国家/地区、默认语言、最低年龄和成人内容范围；
- 正式客户端形态与 Web、Native 的首发顺序；
- 正式注册和登录方式，以及邀请码在增长与准入中的角色；
- Onboarding 必须收集的信息、可跳过项与价值呈现；
- Persona、角色模板、关系记忆、剧情记忆和会话数据的具体可见与编辑能力；
- 免费体验、订阅、虚拟权益与模型档位的关系；
- 用户创作何时开放，以及发布、审核、推荐和下架机制；
- 海外文本、图片和多模态审核 provider、数据区域和人工复核流程；
- 北极星指标“有意义互动”的正式定义与反作弊口径。
