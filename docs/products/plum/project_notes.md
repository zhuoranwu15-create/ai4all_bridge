# Plum 项目临时笔记

更新时间：2026-08-10

> 本文档用于正式 Plum 项目文档建立前的事实交接和风险记录。它不是正式 PRD，也不构成海外审核 provider、数据区域或生产启用的批准。

## 已确认

1. Plum 的 `app_id` 为 `plum`，已纳入平台产品注册和产品级审核策略。
2. Plum 当前审核策略是“共享本地红线 + 不调用外部 provider”。这不等于完整的海外、多语言审核能力。
3. 后续必须正式选定海外 provider 和规则集，并完成数据区域、隐私、留存、故障降级及人工复核评估。
4. 审核 worker 不能根据全局开关直接决定产品能力；必须按任务 `app_id` 解析策略。
5. 入队时保存的规则结果属于审核快照，worker 重试或异步聚合时应复用该结果，不应使用另一套词表重算覆盖。

## 当前实现边界

- Plum 的阿里云入站文本审核固定关闭。
- Plum 的阿里云图片审核固定关闭。
- Plum 的全局 LLM 审核固定关闭。
- Plum 暂时沿用共享本地确定性红线，以避免本地规则为空导致静默放行。
- 未登记产品回落保守策略，并关闭外部 provider。
