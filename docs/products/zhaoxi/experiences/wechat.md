# 朝夕相伴微信端使用说明

更新时间：2026-07-31

适用范围：通过朝夕相伴官网完成手机号注册和微信扫码绑定，随后在微信一对一私聊中使用的
陪伴体验。本文不描述 Native App 的 Companion World；App 开发入口见
[客户端接入说明](../app_client_brief.md)。

## 1. 这是什么

朝夕相伴微信端是一个住在微信私聊里的个人 AI 陪伴对象。每个账号拥有独立的人设、会话、
记忆、提醒和主动消息状态；不同账号之间不能共享或串用这些数据。

它以日常聊天陪伴为核心，也可以帮助设置提醒、查询实时信息、理解图片，以及在合适的时候
跟进之前聊过的话题。它不是公共客服号、群聊机器人，也不替代医生、律师、投资顾问或心理
咨询师。

## 2. 如何开始

1. 打开朝夕相伴官网 `https://ai4company.top/`。
2. 使用中国大陆手机号完成图形验证码和短信验证码验证。
3. 注册成功后，用准备接入朝夕相伴的微信扫描页面二维码。
4. 绑定完成后，在该微信账号的一对一私聊中开始对话。

用户不需要部署 OpenClaw、购买模型 API 或配置服务器。微信连接与模型调用由系统处理。

用户中心 `https://ai4company.top/user/dashboard.html` 可查看贝壳余额、微信绑定状态和个人邀请码。

## 3. 当前支持

- **陪伴式聊天**：支持连续多轮对话；首次聊天会用轻量问题确认彼此称呼和期待的陪伴风格。
- **长期记忆**：结合近期会话、daily notes 和 Dreaming 沉淀长期偏好与重要信息。当前用户侧
  记忆查看和逐条纠错入口仍在建设中。
- **提醒与承诺**：可以用自然语言创建一次性或周期性提醒，也可以继续用自然语言取消或修改。
- **主动消息**：可跟进之前的话题、承诺或内容兴趣；受用户偏好、免打扰时段、频率限制和
  微信送达窗口约束。
- **联网搜索**：搜索能力默认开启；需要实时信息时由 AI 判断是否调用。外部信息仍需结合来源
  和时效自行复核。
- **语音输入**：微信上游成功转写后按普通文本处理；没有可靠转写时不会猜测语音内容。
- **图片理解**：可以识别图片内容、文字、场景和氛围后继续对话；识别失败时会明确提示没看清。
- **账号级隔离**：Soul、会话、记忆、提醒、权益和通道绑定均按账号隔离。

更完整的体验者说明见[朝夕相伴体验者说明](../beta_group_intro.md)。

## 4. 可用指令

在微信私聊中发送：

```text
#状态
```

查看当前会话和账号是否处于可工作状态。

```text
#重置会话
```

清空当前会话中已保存的消息。该指令不等于注销账号，也不会清除全部长期记忆。

## 5. 当前限制

- 只支持一对一私聊，不支持微信群机器人。
- 微信对长时间没有互动的联系人存在约 24 小时的主动送达窗口。超出窗口时，系统主动消息和
  提醒可能无法送达；这是微信通道限制，不代表提醒任务没有创建成功。
- 语音效果依赖上游转写；图片效果依赖媒体传输和视觉模型，失败时均采用保守提示。
- 搜索结果依赖外部搜索源，医疗、法律、金融等重要信息必须进一步核实。
- 长期记忆的用户自助查看、纠错和删除能力尚未完整产品化。
- 当前不支持用户自助更换手机号或完整账号找回；异常绑定需要联系运营处理。

## 6. 与 Native App 的关系

微信端和朝夕 Native App 属于同一个 `zhaoxi` 产品，但不是同一套界面或领域流程：

- 微信端保持一位 AI Agent 的私聊陪伴体验。
- Native App 提供 Companion World、多居民、Feed、信箱、访问和真人会话等产品能力。
- 两种形态共享真人身份和部分平台能力，但会话、Agent 关系状态和产品领域数据按各自作用域管理。

## 7. 数据与隐私说明

为了维持会话连续性、长期记忆、安全审核和故障排查，系统会保存消息、记忆、提醒及必要的
运行记录。运营后台默认以元数据和脱敏视图为主，不能把后台当作全量聊天浏览器。

当前实际持有范围和保留现状见[数据持有说明](../../../ops/data_holding_statement.md)。该文档描述
当前技术事实，不替代正式隐私政策或用户协议。
