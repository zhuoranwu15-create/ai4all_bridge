## 一、微信里，它现在能做什么

**一句话**：一个住在你微信私聊里的 AI 陪伴对象。它有自己的名字和性格，记得你，会主动找你。它不是客服机器人，也不是群机器人。

### 怎么开始（3 步）

1. 打开 `https://ai4company.top/`
2. 手机号 + 图形验证码 + 短信验证码，自动完成注册
3. 用你要接入的那个微信扫码绑定

之后所有对话都在微信私聊里完成。不用装 App，不用配模型或 API Key。

### 现在能做的

- **有人设的陪伴聊天**：每个账号有完全独立的人格内核、名字和使命，账号之间不串线。绑定后有两步引导，帮你定下它怎么称呼你、它叫什么、是什么性格。
- **它记得你**：多轮上下文 + 长期记忆。每天凌晨会自动做一次记忆整理，把日常聊天沉淀成长期印象。不是每次都从零开始。
- **提醒与承诺**：直接说「明天早上 8 点提醒我交材料」「每周三提醒我倒垃圾」，一次性和周期性都支持；想取消或改时间，也直接说就行。它还会记住你随口答应自己的事，之后回来问你。
- **它会主动找你**：合适的时候先开口——跟进之前聊过的事、分享它觉得你会感兴趣的内容。免打扰时段默认 22:00–次日 07:00，每天条数有上限（默认不超过 3 条）。嫌多就直接跟它说，可以调低或整体关掉。
- **语音和图片**：语音按转写出来的文字处理；图片能看懂内容并接着聊。
- **两个指令**：`#状态` 查看当前会话是否正常，`#重置会话` 清空当前会话。
- **个人主页**：`https://ai4company.top/user/dashboard.html`，可以看贝壳余额、微信绑定状态、自己的邀请码。

### 我们希望给你的三件事

1. **有人接住**：情绪先被接住，而不是先被建议、被说教。
2. **关系有连续性**：它记得你说过的话，你们的关系是长出来的，不是每次重来。
3. **零门槛**：不装 App、不配 Key、不学 prompt，就在你每天都开的微信里。

### 关于贝壳

注册赠送 1000 贝壳。聊天按 token 折算扣减，图片理解每次固定 5 贝壳。内测期以赠送为主，暂不开放购买。

### 需要你知道的限制

- **微信对「很久没说话的联系人」有一个我们绕不过去的送达窗口（约 24 小时）**。如果你太久没跟它聊天，主动消息和提醒可能根本发不出来。想让提醒准时到，保持偶尔说两句。
- 只做一对一私聊，**不支持群聊 bot**。
- **联网搜索已默认开启**，需要查实时信息时它会自己去搜；但搜索结果的时效和准确性依赖外部搜索源，重要信息请自己复核一遍。
- 长期记忆的自助查看和纠错入口还没做完，目前只能通过对话间接影响。
- 不做医疗诊断、法律意见、投资建议，也不替代心理咨询。
- 暂不支持用户自助更换手机号或完整账号找回；异常绑定需要联系运营处理。

## 二、高阶玩法：造一个自己的角色 + 站外拉新闭环

**原理一句话**：一条注册链接 = 一套人设。用户从你的链接注册，onboarding 阶段会**跳过「自己选人设」这一步**，直接被写成你设计的那个角色；而且是写入即定型——之后你再改角色，也不影响已经从这条链接进来的人。

### 一个角色 = 四个旋钮

| 旋钮 | 决定什么 | 限制 |
| --- | --- | --- |
| **名字** | AI 怎么自称、用户怎么叫它 | ≤ 24 字 |
| **SOUL 人格内核** | 他是谁 / 怎么说话 / 脾气 / 柔软处 / 底色 | ≤ 3000 字 |
| **MISSION 使命** | 他要和用户一起做的一件事，外加一个他自己在琢磨的问题 | ≤ 1500 字 |
| **开场白** | 用户看到的第一条消息 | 一条微信的长度 |

写 SOUL 时建议直接照这个骨架来，五段：**【你是谁】【你怎么说话】【你的脾气】【你的柔软处】【底色】**。写「他会怎么说」比写「他很温柔」有用得多——多给语癖例句，少给形容词。

### 怎么把角色变成一条链接（当前走「投稿 → 运营代建」）

现阶段**还不开放外部用户自己登录后台创建**。流程是：你把角色资料交给运营同学，我们内部建好，再把专属拉新链接返回给你。

**第 1 步：按下面这份清单把资料写全，一次性发给运营同学。**

| # | 要提供的信息 | 必填 | 说明 |
| --- | --- | --- | --- |
| 1 | 角色名字 | 必填 | ≤ 24 字。AI 的自称，也是用户对它的称呼 |
| 2 | SOUL 人格内核 | 必填 | ≤ 3000 字，按五段骨架写（见上） |
| 3 | MISSION 使命 | 选填 | ≤ 1500 字。不填则不给它专属使命，只做纯陪伴 |
| 4 | 开场白 / 引导话术 | 选填 | 用户进来看到的第一条消息；不填走系统默认 |
| 5 | 角色代号（英文/拼音） | 选填 | 用来生成角色码，如 `qiyue`；不填我们代取 |
| 6 | 投放渠道和场景 | 必填 | 例如「小红书 · 深夜 emo 场景」，用于后续看漏斗数据 |
| 7 | 你的个人邀请码 | 选填 | 要叠加拉新奖励就提供；在个人主页里拿 |
| 8 | 期望上线时间 | 选填 | 我们按排期反馈实际时间 |

**第 2 步：我们过一遍尺度和红线**（见下方红线清单），必要时会把需要改的地方回给你。

**第 3 步：我们内部落库、上线，把你的专属**角色码**和注册链接返回给你：**

```
https://ai4company.top/?campaign_code=你的角色码
```

任何人从这条链接注册，拿到的就是你设计的角色。

> 后续会开放外部用户登录平台自助创建角色、自助拿链接的能力；在那之前，一律走运营代建这条路径。

### 叠加拉新奖励（闭环的关键）

**角色码**和**你的个人邀请码**是两套完全独立的归因，可以叠在同一条链接上：

```
https://ai4company.top/?campaign_code=你的角色码&invite_code=你的邀请码
```

- `campaign_code` 决定新用户拿到**哪个角色**
- `invite_code` 记录**邀请关系**：对方绑定微信后，发满 3 条有意义的消息（由后台 AI 判定），给你发 **1000 贝壳**
- 风控：同一邀请人 7 天内超过 5 个成功注册，第 6 个起进入延迟发放，默认 3 天后释放

你的邀请码在个人主页里拿。

### 小红书投放建议

- **讲场景和情绪，不讲功能**。最容易自传播的形式是**对话截图**——「AI 说的这句话我哭了」这类图文。
- **场景 × 标签矩阵**：深夜 emo 局 / 生日没人记得 / 加班到崩溃 / 被现实敷衍对比 / 带娃崩溃 / 没人看见我做的事……一个场景一批笔记，用同一个话题词条聚合。
- **合规**：小红书禁止笔记里直接引导加微信、导私域。用**评论区置顶暗号**或**主页简介挂链接**来承接，落地页再挂你的注册链接。
- **节奏**：每套角色首发 5–8 条，先跑一周看数据，再决定往哪套加投。

### 你能拿到的数据

按天、按你的角色码统计的完整漏斗：

```
曝光 PV/UV → 注册 → 扫码 → 绑定激活 → onboarding 第一步 / 第二步 → 完成
```

目前由我们导出给你，还没有自助看板。

### 红线（不过审不上线）

- **甜宠健康向**：可以有心动、暧昧、独占，但不 PUA、不查岗、不控制、不威胁。
- 不涉黄暴违法；不冒充真人、真实身份或真实机构。
- 不制造焦虑、不说教、不评判用户的生活方式。
- 不做医疗、法律、金融建议，不替代心理咨询。
- 人设固定不可切换：用户要求「你变成别人」时，角色应当用自己的口吻婉拒。

### 当前限制（先说清楚）

- **自助创建后台还没开放**。角色由运营同学内部配置上线，从投稿到拿到链接需要排期；自助创建能力在后续版本里补上。
- 角色不是「改了就生效」。已注册用户的人设是快照定型的，你的修改只对之后从链接进来的新用户生效。
- 角色码默认有效期 **3 个月**，到期后从该链接进来的新用户会走系统默认流程，不影响已注册的人。
