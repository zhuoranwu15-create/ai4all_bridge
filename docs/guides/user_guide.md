# 用户使用说明

这是当前第一版的简单用户说明。

## 这个服务是什么

AI4ALL 是一个基于微信私聊的个人 AI 陪伴与轻量生活助理服务。

用户通过手机号验证和微信扫码接入微信 OpenClawBot 通道后，就可以在微信里使用由 AI4ALL Backend 驱动的个人 AI bot。用户不需要部署 OpenClaw，也不需要配置模型、服务器或 API Key。

当前产品模型是：

```text
普通用户
-> 手机号验证
-> 微信扫码接入
-> 获得一个独立 AI4ALL Account
-> 在微信私聊里使用个人 AI bot
```

AI4ALL 当前使用 OpenClaw 和官方微信插件完成微信连接，AI4ALL Backend 负责对话、人设、记忆、提醒和配置隔离。OpenClaw 是底层通道能力，不是用户需要理解或配置的产品。

当前定位优先是日常聊天陪伴，同时兼顾明确提醒、后续信息搜索、每日新闻或搞笑内容等轻量助理能力。它不是公共客服微信号，也不是微信群机器人；不是医疗、法律、金融或心理咨询服务。

## 如何使用

1. 打开 Web onboarding 页面：`/ui/onboarding.html`。
2. 输入大陆手机号，完成阿里云图形验证码，并填写短信 OTP。
3. 手机号验证通过后系统自动完成注册，并直接展示微信登录二维码。
4. 用要接入 AI4ALL 的微信扫码。
5. 后续微信私聊消息会经 OpenClaw Bridge 转发给 AI4ALL Backend。
6. AI4ALL Backend 根据该账号的配置生成回复，并通过 OpenClaw 回到微信。

当前已经跑通两个微信账号同时接入同一个 OpenClaw 实例的文本私聊链路。

## 当前支持

- 微信私聊文本。
- 最近会话上下文。
- Backend 调用真实 LLM。
- Web onboarding 自助注册并扫码绑定。
- 手机号短信 OTP + 阿里云图形验证码注册保护。
- AI4ALL 业务账号级隔离。Web onboarding 绑定后使用预创建的 `aid_...` 账号。
- 每个账号自动拥有独立的 context files：`SOUL.md`、`IDENTITY.md`、`USER.md`、`MEMORY.md`。
- 明确时间的一次性提醒已进入早期验证链路。
- 语音输入依赖 `openclaw-weixin` 上游转写文本；转写成功后按普通文本处理。
- Web Search、主动内容邀请和 hidden commitment 是内测开关能力，按账号/环境配置启用。
- 后端已有 daily notes、Dreaming 和长期记忆写入链路；用户自助查看、纠错和管理入口仍在补齐。
- 运营人员可以通过 Admin API 查看账号、会话元数据、用量、钱包和主动消息状态；正文默认脱敏。

## 可用指令

在微信私聊中发送：

```text
#状态
```

查看当前会话是否正常。

```text
#重置会话
```

清空当前会话已存储的消息。

## 当前限制

- 语音消息依赖上游转写质量；没有转写文本时只能按占位文本进入对话。
- 图片理解已支持；图片未收到、太大、传输失败或识别失败时，会提示没看清，不会猜图片内容。
- 群聊 bot 暂不支持。
- 信息搜索、每日新闻和搞笑内容推送仍属于灰度/内测能力，不保证所有账号默认开启。
- 长期记忆的用户自助管理还没有完整产品化。
- 手机号注册当前只支持大陆 11 位手机号。
- 当前还没有正式登录态、找回账号、手机号变更或用户自助管理界面。

## 隐私说明

为了维持会话上下文和便于排查问题，消息会被 AI4ALL Backend 存储。

在对外正式开放前，需要补充正式的隐私政策、数据保留策略和用户告知机制。
