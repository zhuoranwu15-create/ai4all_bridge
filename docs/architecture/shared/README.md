# 共享架构

本目录记录可被多个产品复用、且不得依赖任何具体产品命名空间的技术事实。

| 子目录 | 范围 |
| --- | --- |
| [`access/`](access/) | 身份、渠道、OpenClaw/Bridge、节点接入与解绑 |
| [`platform/`](platform/) | 审核、计费/权益、媒体、隐私、观测与稳定性 |
| [`data/`](data/) | 多产品数据隔离、数据库/文件系统边界、PostgreSQL 架构 |

共享设计不得以朝夕或 Fatetell 的领域对象作为输入、输出或依赖；确需产品差异时，应通过产品
manifest、注册表或明确端口表达，并在对应产品设计中记录。
