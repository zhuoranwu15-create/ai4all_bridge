# 用户使用说明

这是当前第一版的简单用户说明。

## 这个服务是什么

AI4ALL 是一个基于微信私聊的个人 AI 陪伴与生活助理。

当前使用 OpenClaw 和官方微信插件完成微信连接，AI4ALL Backend 负责对话、人设、记忆和配置隔离。

当前产品模型是：

```text
一个 OpenClaw 实例
-> 多个个人微信账号接入
-> 每个账号拥有自己的 AI bot 会话
-> 每个账号独立 Soul、上下文和配置
```

它不是一个公共服务微信号，也不是一个微信群机器人。

当前定位是日常陪伴和生活助理，不是医疗、法律、金融或心理咨询服务。

## 如何使用

1. 打开 Web onboarding 页面：`/ui/onboarding.html`。
2. 输入大陆手机号，完成阿里云图形验证码，并填写短信 OTP。
3. 手机号验证通过后填写昵称，完成注册。
4. 创建自己的智能体，设置名称和角色设定。
5. 生成微信绑定二维码，并用要接入 AI4ALL 的微信扫码。
6. 后续微信私聊消息会经 OpenClaw Bridge 转发给 AI4ALL Backend。
7. AI4ALL Backend 根据该账号的配置生成回复，并通过 OpenClaw 回到微信。

当前已经跑通两个微信账号同时接入同一个 OpenClaw 实例的文本私聊链路。

## 当前支持

- 微信私聊文本。
- 最近会话上下文。
- Backend 调用真实 LLM。
- Web onboarding 自助注册、创建智能体和扫码绑定。
- 手机号短信 OTP + 阿里云图形验证码注册保护。
- AI4ALL 业务账号级隔离。Web onboarding 绑定后使用预创建的 `acct_...`。
- 每个账号自动拥有独立 `user_profile.md`。
- 运营人员可以通过 Admin API 查看账号、会话和消息。

## 可用指令

在微信私聊中发送：

```text
#状态
```

查看当前会话是否正常。

```text
#重置会话
```

清空当前会话已存储的消息。

## 当前限制

- 语音消息还没有完整支持。
- 图片暂不支持。
- 群聊 bot 暂不支持。
- 长期记忆还没有产品化。
- 手机号注册当前只支持大陆 11 位手机号。
- 当前还没有正式登录态、找回账号、手机号变更或用户自助管理界面。

## 隐私说明

为了维持会话上下文和便于排查问题，消息会被 AI4ALL Backend 存储。

在对外正式开放前，需要补充正式的隐私政策、数据保留策略和用户告知机制。
